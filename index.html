Email to Excel Follow-up Tracker

Convert Outlook emails into an Excel follow-up tracker. Without an API key, processing stays in your browser. With a key, email text is sent to your selected AI provider.

1. Select emails

    Processing mode

    11 readable files = 11 data rows. Attached emails are context, not extra rows.

    Recursively lists the innermost attached emails. Container emails are not separate rows; a file without attached emails contributes its own row.

    2. Summary and original issue excerpt (optional AI)

    Enter your DeepSeek API key for an English one-sentence topic Summary and a short original excerpt of the core issue or request.
    Leave the key blank to use original-text excerpts without AI.
    Your key stays in this page only and is cleared when you reload or close it. Use AI only when permitted to share the email content with your selected provider.

    Ready to use with deepseek-flash. Only your API key is required.

    If AI fails, an error and confirmation dialog appear. Original-excerpt fallback requires your approval; Cancel stops the batch without an Excel download.

    Advanced: change provider or model

    Both fields are editable. Use an OpenAI-compatible HTTPS endpoint and its matching API key. Blank fields use the DeepSeek defaults.

    3. Export the entire batch to one Excel file

    Summary distills the topic into one sentence. Issues description quotes only the core original sentences, excluding openings, closings and signatures. For multilingual emails, one English or French version is sufficient. All original excerpts are enclosed in double quotes.
